# Dapur Seruni (situs contoh)

Landing page contoh untuk usaha katering nasi kotak. **Usaha, harga, testimoni, dan nomor WhatsApp di situs ini fiktif**,
dibuat sebagai contoh portofolio, bukan usaha nyata.

- Demo: https://hadischolar6.github.io/dapur-seruni/
- Dibangun dengan [AstroWind](https://github.com/arthelokyo/astrowind) (lisensi MIT, lihat `LICENSE.md`), Astro + Tailwind CSS.
- Foto: Unsplash (lihat `CREDITS.md`).
- Repo ini hanya berisi hasil build statis.
